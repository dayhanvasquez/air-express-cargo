# Air Express Cargo — Sitio web

Sitio estático (HTML, CSS y JavaScript) publicado con GitHub Pages.

- `index.html` — Inicio: hero con pestañas Rastrear | Cotizar, servicios, cómo funciona, nosotros y contacto.
- `cotizar.html` — Cotizador B2B en 3 pasos (ruta, carga con bultos/pallets opcionales, contacto) con resumen lateral. No calcula precio: genera un correo para que un ejecutivo envíe la tarifa.
- `styles.css`, `script.js` — estilos e interacciones.

Para cambiar el correo de destino, edita `CONTACT_EMAIL` al inicio de `script.js`. Teléfono y correo de contacto en los HTML son provisorios.
